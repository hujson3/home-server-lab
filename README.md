# Home Server Lab

Domowy homelab zbudowany na bazie laptopa Acer Aspire 5.

## Hardware

- Intel Core i3-8130U
- 12 GB RAM
- SSD 512 GB
- dodatkowy HDD planowany jako magazyn/NAS
- Debian 13

## Aktualne usługi

- Docker
- Docker Compose
- Portainer
- Uptime Kuma
- AdGuard Home
- Tailscale
- Glances

## Funkcje

- zdalne zarządzanie przez SSH
- stały adres IP przez rezerwację DHCP
- monitoring usług i zasobów
- filtrowanie DNS / blokowanie reklam dla sieci domowej
- zdalny dostęp przez Tailscale
- automatyczne backupy konfiguracji

## Plan rozwoju
