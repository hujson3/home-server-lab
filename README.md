# Home Server 

Serwer do użytku domowego przy wykorzystaniu starego laptopa Acer

## Hardware

CPU: Intel Core i3-8130U
RAM: 12 GB
Dysk: SSD 512 GB
System: Debian 13


## Uslugi

- Docker
- Docker Compose
- Portainer
- Uptime Kuma
- AdGuard Home
- Tailscale
- Glances


## Funkcje

- zdalne zarządzanie przez SSH
- Zarezerwowany adres IP w sieci
- monitoring wszystkich usług
- filtrowanie DNS
- dostęp zdalny przez Tailscale
- automatyczne backupy
- zarządzanie kontenerami


## Zaplanowane

- NAS
- dodatkowy dysk HDD na przechowywanie backupów oraz do udostępnienia w sieci
- centralny monitoring
- Jellyfin
- hosting gier do gry ze znajomymi :D
